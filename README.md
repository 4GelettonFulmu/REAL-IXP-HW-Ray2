# Ecological Cycle Simulator 🌳💩🐕

An interactive, visual game experience showcasing an ironic ecological cycle, rendered in the distinctive **tokidoki × NIGO** aesthetic. This is a completely visual game with no text, numbers, or UI elements—all information is conveyed through rich animations, colors, expressions, and visual symbols.

## 🎮 Game Concept

Experience an endless, ironic ecological cycle:

1. **Dogs** defecate in roadside grass 🐕💩
2. The **grass** is fertilized and grows into a large **tree** 🌱➡️🌳
3. The tree attracts **birds** to nest 🐦
4. As birds multiply, they defecate from the sky 💩☁️
5. **Humans** get hit by bird droppings and become angry 😠
6. Humans cut down the tree to make **toilets** to avoid the droppings 🚽
7. Humans walk their dogs again, and the cycle repeats endlessly ♻️

## 🎨 Visual Style

### tokidoki × NIGO Crossover Aesthetics

- **Dogs**: Huge round eyes with star highlights, glossy vinyl toy appearance, gradient/camo patterns, candy colors (mint green, cherry blossom pink, cream yellow)
- **Trees**: Living characters with faces, heart-shaped eyes, BAPE camouflage patterns, rainbow gradient canopies
- **Birds**: Chibi-style round bodies, metallic sheen feathers, pearl-like eyes, star accessories
- **Humans**: Trendy streetwear figures with logo patterns, simplified dot-and-line expressions
- **Environment**: Fluorescent gradients, breathing animations, glowing edges, floating decorative particles (stars, hearts, musical notes)

## ✨ Animation Systems

### 1. Idle Animations
All characters move even when inactive:
- Dogs breathe, blink, wag tails, shift weight
- Trees sway, blink, breathe
- Birds bob, turn heads, flap wings gently
- Clouds drift, blink, change expressions
- Grass blades sway independently with sparkling tips

### 2. Interactive Feedback Animations
Click-triggered instant feedback:
- Screen vibration
- Dog pooping sequence with straining animation
- Poop bounces and emits stink clouds
- Grass contact triggers golden flashes
- Victory poses and celebrations

### 3. State Transition Animations
Complex upgrade sequences:
- Poop absorption into grass with flying animation
- Upgrade beam from ground to sky
- Growth transformations: sprout → bush → shrub → sapling → tree
- Birds flying in with rainbow trails
- Tree chopping with impact effects
- Toilet construction animation

### 4. Environmental Animations
Continuous atmosphere building:
- Sky gradient color cycling (10-second intervals)
- Cloud movement and expression changes
- Decorative particle generation (stars every 2s, hearts every 3s, notes every 4s)
- Grass wave animation from wind
- Fireflies circling the tree
- Parallax scrolling between layers

## 🎯 How to Play

1. **Click anywhere** on the screen to make the dog poop
2. **Watch** as poop accumulates (5 poops needed for upgrade)
3. **Observe** the grass grow through multiple stages
4. **Experience** the tree transformation and bird arrival
5. **React** as birds start pooping on the human
6. **Witness** the human's escalating anger and tree destruction
7. **Watch** the toilet construction and cycle reset

## 🎭 Visual Status Indicators

No text or numbers! Status shown through:
- **Poop count**: Actual poop piles visible (1-5)
- **Vegetation level**: Visible plant size
- **Bird count**: Number of birds in the tree
- **Toilet count**: Buildings in background
- **Human mood**: Facial expressions (happy → surprised → angry → rage)
- **Progress cues**: Glowing grass, nest icons, darkening sky

## 🎨 Seven Visual Layers

1. **Background**: Large gradient sky
2. **Distant clouds**: Small, slowly moving
3. **Mid-ground clouds**: Large with expressions
4. **Ground**: Textured sidewalk and soil
5. **Main objects**: Grass, trees, toilets, humans (with shadows)
6. **Characters**: Dogs and birds (with dynamic shadows)
7. **Foreground**: Particles with bloom effects
